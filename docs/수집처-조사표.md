- 조사일: 2026-09-23. 사이트 66곳(방·집 매물, 경매·공매, 공공데이터·공고). 2026-10-03에 신탁사 공매·코리빙·HUG 든든전세 등을 더 조사했습니다(아래 '2026-10-03 추가 조사').
- 기준: 거래 유형, 공식 API, robots.txt, 약관의 자동수집 조항. 권장 방식 분포: 공식 API 14곳 · 저빈도 자동수집 후보 9곳 · 수동 확인·앱 알림 30곳 · 제외 13곳.

## 조사 방법과 한계

- 사이트마다 robots.txt를 직접 조회하고, 이용약관·저작권정책의 자동수집 관련 조항을 찾았습니다. 로그인, 폼 제출, 비공개 API 호출, 차단 우회는 하지 않았습니다.
- **직접 수집 위험**: 높음은 약관의 명시적 금지, 방화벽 차단, robots의 크롤링 금지 고지 중 하나가 있는 경우입니다. 중간은 명시 조항은 없지만 robots가 매물 경로나 전체를 막거나 약관을 확인하지 못한 경우입니다. 낮음은 robots가 허용하고 명시적 금지도 없는 경우이고, 공식 API도 낮음으로 봤습니다.
- 약관은 원문 대신 요지로 옮겼습니다. 약관과 robots는 바뀔 수 있으니 수집기를 켜기 전에 다시 확인해야 합니다.
- 법률 자문이 아닙니다. 개인이 혼자 비영리로 쓰는 것을 전제로 평가했습니다.
