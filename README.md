# 회사근처 내집마련

켜 둔 지역(지하철역과 반경) 근처의 매물, 경매와 공매 물건, 임대와 청약 공고를 여러 곳에서 모아
**새로 올라온 것과 가격이 바뀐 것만** 알려 주는 개인용 로컬 도구입니다.
판단은 사용자가 합니다. 도구가 매물을 골라 버리지는 않습니다(사이트에서 내려간 매물만 목록에서 빠지고, 시간이 지나면 지웁니다).

## 하는 일

- **모으기:** 프로그램이 직접 조회하는 곳은 '조회하기'를 누르거나 정해 둔 시각에 조회용 크롬으로 돌고, 나머지 사이트는 사용자가 평소 크롬으로 볼 때 크롬 확장이 그 화면이 받은 데이터를 대시보드로 보냅니다.
- **새 소식:** 지역과 사이트마다 처음 모은 것은 기준으로만 저장하고, 그 뒤에 새로 보인 매물과 가격이 바뀐 매물을 따로 표시하고 셉니다.
- **알림:** 조회가 끝나면 전월세 쪽과 매매 목적(매매, 경매, 청약)을 나눠 윈도우 알림을 띄우고, 누르면 그 매물이나 탭이 열립니다. 알릴 항목과 금액 상한은 설정 탭에서 정합니다.
- **자동 확인:** 정해 둔 요일과 시각에 조회를 돌립니다. 그 시각에 컴퓨터가 꺼져 있었으면 다음에 켤 때 돕니다(윈도우 작업 스케줄러).
- **보기:** 거래 유형과 가격대로 묶은 목록과 지도, 경매와 공매(매각 결과, 예상 낙찰가, 배당 순위 확인), 집터, 청약, 임대 공고, 시세 통계, 지원 제도, 체크리스트, 사기 사례 탭.
- **과정 공개:** 조회 기록, 요청 기록, 스크린샷, 원본 데이터를 남겨 무엇을 어떻게 받았는지 다시 볼 수 있습니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `server/` | Fastify 서버, 수집기(`collectors/`, Playwright), SQLite 저장(better-sqlite3), 알림(node-notifier), 자동 확인, 첨부 파일 읽기 |
| `web/` | 대시보드(Vue 3, Vite, Leaflet 지도) |
| `extension/` | 크롬 확장(Manifest V3, 빌드 없는 JS) |
| `shared/` | 서버와 화면이 같이 쓰는 타입과 형식 함수 |
| `launcher/` | 아이콘으로 켜기와 사이트 창 열기 |
| `scripts/` | 시험(`node:test`) |

- 수집기는 조회용 크롬으로 화면을 열고, 그 화면이 불러오는 응답을 함께 읽습니다. 쪽과 사이트 사이를 쉬고, 403이나 429를 받으면 그 사이트 조회를 멈춥니다.
- 크롬 확장은 페이지의 `fetch`와 `XMLHttpRequest` 응답을 복사해 로컬 서버로 보냅니다. 로그인과 개인 정보 요청은 거르고, 전화번호와 메일 주소는 가립니다. 대시보드가 꺼져 있으면 매물 목록 응답을 확장에 모아 두었다가 켜지면 보냅니다.
- 공고 첨부 파일(PDF, HWP, HWPX, XLSX)에서 글자와 표를 뽑고, 글자가 그림으로 된 PDF는 윈도우 글자 인식(OCR)으로 읽습니다.
- 경매 물건 좌표는 KATEC에서 위경도로 바꿉니다(proj4).

## 실행

**아이콘으로 켜기**

- 윈도우: 프로젝트 맨 위의 `대시보드 켜기 - 윈도우.cmd`를 누릅니다(바탕 화면에 바로 가기를 만들어 두면 편합니다). 서버를 켜고, 크롬 새 창 하나에 확장에서 켜 둔 사이트들과 맨 끝 탭에 대시보드를 엽니다. 조회는 하지 않습니다.
  - 작업 표시줄에 최소화된 창이 하나 생기는데, 그 창이 서버입니다. 닫으면 꺼집니다.
  - 이미 켜져 있으면 창만 엽니다. 켜 둔 지역이 없거나 크롬이 없으면 대시보드만 엽니다.
- 맥: `대시보드 켜기 - 맥.command`를 두 번 누릅니다. 터미널 창이 서버이고, 닫으면 꺼집니다. 윈도우에서 복사해 온 폴더라 실행 권한이 없으면 처음 한 번은 터미널에서 `sh "대시보드 켜기 - 맥.command"`로 엽니다.
- 두 파일 모두 `launcher/start.mjs`를 부릅니다. 처음이거나 다른 컴퓨터에서 옮겨 온 폴더면 패키지를 새로 깔고, 화면을 빌드한 뒤 서버를 켭니다. Node.js(LTS)와 크롬이 필요합니다.

**명령으로 켜기**

```bash
npm install
npm start
```

- `npm start`: 화면을 빌드한 뒤 서버를 띄우고 <http://localhost:8787>을 엽니다.
- `npm run dev`: 서버와 Vite를 함께 띄웁니다(<http://localhost:5173>).
- `npm test`는 시험, `npm run typecheck`는 타입 검사입니다.

**크롬 확장 설치(한 번만)**

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트의 `extension` 폴더를 고릅니다.

확장 아이콘을 누르면 사이트마다 켜고 끄는 스위치와 지역 목록이 나옵니다. 켠 사이트에서만 동작하고, 확장 파일이 바뀌면 1분 안에 스스로 다시 불러옵니다.

**이 컴퓨터 설정(`config/local.json`)**

저장소에 올리지 않는 설정 파일입니다. 없으면 기본값으로 돕니다.

```json
{
  "defaultAreas": [{ "station": "강남역", "radiusM": 1000, "enabled": true }],
  "knownStations": ["강남역", "역삼역", "신논현역"],
  "dataGoKrKey": "공공데이터포털 인증키",
  "vworldKey": "브이월드 인증키"
}
```

- `defaultAreas`: 처음 켤 때 만드는 지역입니다. 역 이름은 `server/stations-kric.json`에 있는 이름을 씁니다. 없으면 지역 없이 시작하고 지역 탭에서 고릅니다.
- `knownStations`: 지역과 상관없이 늘 아는 역입니다. 역 단위로 모으는 수집기, 경매 구 고르기, 임대 공고의 '근처' 판단에 씁니다.
- `dataGoKrKey`: 서울 아파트 탭에서 경매와 공매 아파트의 세대수를 건축물대장으로 채울 때 씁니다. 공공데이터포털에서 [국토교통부_건축HUB_건축물대장정보 서비스](https://www.data.go.kr/data/15134735/openapi.do)를 활용신청하고 마이페이지의 일반 인증키를 넣습니다.
- `vworldKey`: 집터, 경매, 서울 아파트 탭의 재개발 구역 경고에 씁니다. 브이월드에서 [오픈API 인증키](https://www.vworld.kr/dev/v4dv_apikey_s001.do)를 신청할 때 서비스 URL은 `http://localhost`로 적고, 활용 API는 '국가중점 API'를 고릅니다(매매 아파트 단지 좌표로 필지를 찾으려면 '2D 데이터 API'도). 서비스 URL을 다르게 적었으면 `vworldDomain`에 그 주소를 넣습니다.
- 조회용 브라우저로 설치된 크롬을 씁니다. 크롬이 없으면 `npx playwright install chromium`을 한 번 실행합니다.
- 데이터는 `data/`(SQLite 파일, 스크린샷, 조회용 브라우저 프로필)에 저장되고 저장소에는 올라가지 않습니다.

## 조회할 때 보이는 것

설정 탭에서 '브라우저 창 띄워서 보면서 조회'를 켜 두면 조회용 크롬 창이 떠서, 프로그램이 사이트를 조작하는 모습을 그대로 볼 수 있습니다.

- **빨간 화살표:** 창 안에서만 움직이는 커서입니다. 실제 마우스는 건드리지 않습니다.
- **진행 띠:** 페이지 아래쪽에 지금 하는 일을 보여 줍니다. 커서가 다가오면 비켜서 조작하는 곳을 가리지 않습니다.
- **카드 배지와 테두리:** 읽은 매물에 신규, 기존, 버림, 관심이 붙습니다.
