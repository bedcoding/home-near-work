# 회사근처 내집마련 (프로토타입)

설정한 지역(역과 반경)의 매물과 경매 물건을 **'조회하기'를 누르거나 하루 한 번 정한 시각에** 모아서,
**새로 올라온 것과 가격이 바뀐 것만** 따로 보여 주는 개인용 도구입니다.
판단은 사용자가 합니다. 도구가 매물을 골라 버리지는 않습니다(사이트에서 내려간 매물만 목록에서 빠지고, 시간이 지나면 지웁니다).

## 실행

**아이콘으로 켜기(권장)**

- 윈도우: 바탕 화면의 **회사근처 내집마련 대시보드** 아이콘을 누릅니다(프로젝트 맨 위의 `대시보드 켜기 - 윈도우.cmd`를 부름). 크롬 새 창 하나에 부동산 사이트 6곳(네이버가 첫 탭)과 맨 끝 탭에 대시보드가 열립니다. 조회는 하지 않습니다.
  - 작업 표시줄에 최소화된 창이 하나 생기는데, 그 창이 대시보드입니다. **닫으면 꺼집니다.** 크롬 확장이 보내는 데이터를 받으려면 켜 두세요.
  - 이미 켜져 있으면 창만 엽니다. 아이콘을 오른쪽 클릭해 작업 표시줄이나 시작 화면에 고정할 수 있습니다.
  - 켜 둔 지역이 없거나 크롬이 없으면 대시보드만 엽니다.
- 맥: 프로젝트 맨 위의 `대시보드 켜기 - 맥.command`를 두 번 누르거나 Dock에 끌어다 두고 누릅니다. 터미널 창이 대시보드이고, 닫으면 꺼집니다.
  - 윈도우에서 복사해 온 폴더면 실행 권한이 없어서, 처음 한 번은 터미널에 `sh `를 치고 이 파일을 끌어다 놓은 뒤 Enter를 눌러야 할 수 있습니다. 그 뒤로는 두 번 누르면 열립니다.
  - 처음 켤 때 필요한 패키지를 깔고(몇 분), 이 파일에 집 아이콘을 입힙니다. 맥에서는 아직 시험하지 못했습니다.
  - Node.js(LTS)와 크롬이 필요합니다. 크롬 확장은 맥의 크롬에도 따로 설치해야 하고, 데이터(`data/`)는 컴퓨터마다 따로입니다.
- 두 파일 모두 `launcher/start.mjs`를 부릅니다. 처음이거나 다른 컴퓨터에서 옮겨 온 폴더면 패키지를 새로 깔고, 화면을 빌드한 뒤 서버를 켜고 위 크롬 창을 엽니다.

**명령으로 켜기**

```bash
npm install
npm start
```

`npm start`는 화면을 빌드한 뒤 서버를 띄우고 브라우저에서 <http://localhost:8787>을 엽니다.
개발할 때는 `npm run dev`로 띄우고 <http://localhost:5173>을 엽니다.

**이 컴퓨터 설정(`config/local.json`)**

저장소에 올리지 않는 설정 파일입니다. 없으면 기본값으로 돕니다.

```json
{
  "defaultAreas": [{ "station": "강남역", "radiusM": 1000, "enabled": true }],
  "knownStations": ["강남역", "역삼역", "신논현역"],
  "celibBranches": [{ "name": "셀립 지점 이름", "slug": "지점 화면 주소의 이름", "p": 0 }],
  "dataGoKrKey": "공공데이터포털 인증키",
  "vworldKey": "브이월드 인증키"
}
```

- `defaultAreas`: 처음 켤 때 만드는 지역입니다. 역 이름은 `server/stations-kric.json`에 있는 이름을 씁니다. 없으면 지역 없이 시작하고 지역 탭에서 고릅니다. 이미 지역이 있으면 쓰지 않습니다.
- `knownStations`: 지역과 상관없이 늘 아는 역입니다. 집토스 역 페이지, 법원경매 구, 임대 공고의 '근처' 판단에 씁니다. 지역으로 만든 역은 따로 적지 않아도 됩니다.
- `celibBranches`: 모을 셀립 지점입니다. 없으면 셀립은 모으지 않습니다.
- `dataGoKrKey`: 실거래가에 쓸 공공데이터포털 인증키입니다(아래 '다음 단계'의 실거래가).
- `vworldKey`: 재개발 구역 경고(집터, 경매, 서울 아파트, 관심, 숨김함 탭)에 쓸 브이월드 인증키입니다(아래 집터 탭). 키를 받을 때 서비스 URL을 `http://localhost`가 아닌 것으로 적었으면 `vworldDomain`에 그 주소를 넣습니다.

- 조회용 브라우저로 설치된 크롬을 씁니다. 크롬이 없으면 `npx playwright install chromium`을 한 번 실행하세요.
- 데이터는 전부 이 폴더의 `data/`에 저장됩니다(SQLite 파일, 스크린샷, 조회용 브라우저 프로필).

## 조회할 때 보이는 것

'브라우저 창 띄워서 보면서 조회'를 켜 두면 조회용 크롬 창이 떠서, 프로그램이 사이트를 조작하는 모습을 그대로 볼 수 있습니다.
- **빨간 화살표:** 창 안에서만 움직이는 커서입니다. 실제 마우스는 건드리지 않으니 그동안 컴퓨터를 써도 됩니다.
- **진행 띠:** 페이지 아래쪽에 지금 하는 일을 보여 줍니다. 커서가 다가오면 위아래로 비켜서 조작하는 곳을 가리지 않습니다.
- **카드 배지와 테두리:** 읽은 매물에 신규·기존·버림·관심이 차례로 붙습니다. '기존'은 지난 조회에서 이 프로그램이 이미 모은 매물입니다(직접 본 매물이라는 뜻이 아님, 마우스를 올리면 뜻이 보임).
- **사이트별 조작 순서**
  - 집토스: 역 페이지를 열고 카드와 아래쪽 표에 표시를 붙인 뒤 끝까지 스크롤합니다.
  - 피터팬: 역 위치로 지도를 열고, 목록에 가려진 만큼 지도를 끌어 역을 가운데로 맞춘 뒤 목록을 휠로 끝까지 내립니다. 휠로 더 안 불러와지는 쪽은 같은 목록 주소로 이어 받고, 요청 기록에 따로 표시합니다.
  - 법원경매: 물건상세검색에서 소재지(서울특별시 > 구)와 용도(건물 > 주거용건물)를 고르고 검색한 뒤 결과를 40건씩 봅니다. 검색 결과는 목록(토지·호실)마다 한 줄이라, 한 번에 매각하는 물건(같은 사건·물건번호)은 한 건으로 합칩니다.

## 쓰는 법

- **조회하기:** 바탕 화면 아이콘(맥은 .command)으로 켜면 대시보드와 사이트 창이 열리기만 합니다. 위쪽 '조회하기'를 눌러야 아래 '지금 수집하는 곳'의 매물 사이트와 공고를 전부 모읍니다.
- **자동 확인:** 설정 탭의 '자동 확인'에서 요일(매일 또는 매주 한 요일)과 시각을 고르면 그때 알아서 조회합니다(기본 매일 22:30, 맨 위 오른쪽에 '자동 확인 매주 토요일 10:00'처럼 보이고 누르면 설정 탭). 그 시각에 대시보드나 컴퓨터가 꺼져 있었으면 다음에 컴퓨터를 켤 때 대시보드를 창 없이 켜고 그 확인을 돌립니다(윈도우). 조회용 창은 '브라우저 창 띄워서 보면서 조회' 설정을 따릅니다.
  - **공고 확인:** 설정 탭의 '공고 확인'에서 시각을 고르면 매일 그 시각에 매물 사이트는 빼고 공고만 창 없이 모읍니다(맨 위 오른쪽에 ', 공고 매일 22:30'). 켜 둔 지역 바로 근처일 가능성이 높은 새 임대 공고(아래 '근처')가 있을 때만 바로 알림이 뜨고, 나머지 새 공고는 모아 두었다가 다음 매물 조회('조회하기'나 자동 확인)의 알림에 함께 넣습니다. 조회 기록에는 '자동, 공고만'으로 남고, '마지막 조회'에는 넣지 않습니다. 자동 확인 시각과 겹치면 자동 확인을 먼저 합니다(공고도 같이 모음).
  - **윈도우 예약:** 요일이나 시각을 바꾸면 윈도우 작업 스케줄러의 '회사근처 내집마련 자동 확인' 작업도 같이 바뀌고(공고 확인 시각은 같은 작업에 매일 트리거로 붙음), 둘 다 끄면 지워집니다. 작업은 `data/auto-check.lnk`(최소화로 실행)를 열고, 그 바로 가기가 `대시보드 켜기 - 윈도우.cmd --check`를 부릅니다(창은 열지 않고, 대시보드가 답하면 놓친 확인을 돌림). 대시보드는 그 뒤에도 켜져 있어서 알림을 누르면 바로 열립니다. 바탕 화면 아이콘으로 켜기만 해서는 조회하지 않습니다. 맥에서는 작업을 걸지 않아 대시보드가 켜져 있을 때만 돕니다.
  - **알림 고르기:** 설정 탭에서 알림마다 켜고 끄고 금액 상한을 적습니다(만원, 빈칸은 제한 없음, 바꾸면 바로 저장). 처음에는 월세 50만 이하, 고시원과 쉐어, 임대 공고, 경매, 공매 공고, 청약, 가격 변동, 수집 실패가 켜져 있고 전세, 단기, 매매는 꺼져 있습니다.
    - 매물 줄: 월세(월세, 보증금 상한), 전세(전세금), 단기(월세), 고시원과 쉐어(가장 싼 방 월세), 매매(매매가), 경매(최저가), 서울 아파트 경매(최저가). '매물은 지역 반경 안만'을 켜 두면 켜 둔 지역 반경 안 매물만 셉니다. 대시보드 필터와는 따로입니다.
    - 서울 아파트 경매 줄은 서울 아파트 탭에서 고른 구의 새 아파트 경매·공매를 지역 반경과 상관없이 셉니다(경매 줄에 이미 든 것은 빼고). 알림을 누르면 서울 아파트 탭이 열립니다.
    - 공고 줄: 임대 공고(켜 둔 지역 근처 것만), 공매 공고, 청약, 상가 공고와 토지 공고(LH, 켜 둔 지역 근처 것만).
    - 가격 변동은 바뀐 가격이 켜 둔 매물 줄에 맞는 매물만 셉니다. 버린 매물은 세지 않습니다.
    - 직접 보는 사이트: 바탕 화면 아이콘이나 '한 번에 열기'로 사이트를 열면, 다 뜬 뒤(마지막 데이터 8초 뒤) '새 매물: 다방 1건, KB +5, 네이버 +3'처럼 알림 하나가 뜹니다. 다방은 새 방 중 위 매물 줄에 맞는 수, KB와 네이버는 전에 본 같은 조건보다 늘어난 매물 수입니다(가격 조건으로는 못 거름). 사이트 탭 '직접 보기' 줄에도 사이트마다 마지막 결과가 보입니다.
  - **알림은 둘로 나뉘어 뜹니다.** 전월세 줄(월세, 전세, 단기, 고시원과 쉐어, 임대 공고)과 매매 목적 줄(매매, 경매, 서울 아파트 경매, 공매 공고, 청약, 상가 공고, 토지 공고)입니다.
    - 제목은 켜 둔 줄마다 수입니다. 줄이 하나뿐이면 '월세 50만 이하 새 매물 3건', 여럿이면 '월세 50만 이하 2건, 임대 공고 1건'이고, 매매 목적은 '매매 목적: 경매 2건, 청약 1건'처럼 앞에 붙습니다. 그 아래에 사이트별 수, 공고 곳별 수, 가격 변동, 실패한 사이트가 붙습니다.
    - 매일 자동 확인은 새 소식이 있는 쪽만 띄웁니다. 요일을 정한 자동 확인과 '조회하기'는 아무것도 없으면 '조회 끝: 새 소식 없음'과 이번에 확인한 켜 둔 알림을 띄웁니다.
  - **알림을 누르면:** 제목 맨 앞 줄의 새 소식이 하나면 그 원본 화면(법원경매는 경매 탭), 여럿이면 그것이 보이는 대시보드 탭이 열립니다. 가격 변동만 있으면 그 매물들, 실패만 있으면 조회 기록 탭입니다.
  - 요일이나 시각을 바꾸면 이미 지난 확인 시각은 돌리지 않고 다음 시각부터 돕니다. 놓친 확인이 남아 있으면(윈도우 예약이 아직 돌지 않았거나 맥) 맨 위에 '자동 확인 놓침, 지금 확인' 버튼이 보입니다.
  - 그 시각 전 2시간 안이나 그 뒤에 이미 조회했으면 그 확인은 건너뜁니다. 조회 기록 탭에는 '자동'으로 표시됩니다.
- **중단:** 조회 중에 위쪽 진행 표시줄의 '중단'을 누르면 멈춥니다. 다 모은 사이트 결과는 남고, 하던 사이트는 받은 것까지만 저장합니다.
- **탭 하나만 조회:** '조회하기' 옆 ▾를 누르면 탭 하나에 보이는 것만 모읍니다. 지금 보고 있는 탭에는 '지금 탭'이 붙습니다. 다른 탭의 매물과 공고는 그대로 두고(사라짐으로 바꾸지 않음), 조회 기록과 '마지막 조회'에 '임대 공고만'처럼 남습니다.
  - 매물: 집토스, 피터팬, 고방. 네이버, 다방, 직방은 '한 번에 열기'로 크롬 확장이 모읍니다.
  - 경매·집터·서울 아파트: 법원경매, 온비드, 신탁 공매 공고, LH 상가와 토지 공고. 경매 탭, 집터 탭, 서울 아파트 탭의 '경매 조회하기'와 같습니다. 서울 아파트 탭에서 고른 구의 아파트도 같이 모읍니다.
  - 고시원과 쉐어: 고방, 에피소드, 맹그로브, 셀립
  - 임대 공고: SH, LH, 고방, 마이홈, HUG, 청약홈(임대), LH 선착순
  - 청약: 청약홈, SH, LH 분양, LH 선착순
  - 시세 통계: 시세 통계 탭의 '지금 받기'와 같습니다(KB 지수, 국토부 아파트 실거래).
  - 실거래와 KB 통계, 정비구역 지도 파일은 그 탭이 쓰는 것만 받습니다. 경매 범위는 받은 지 7일이 지났으면 단독 실거래와 아파트 실거래 최근 1년을 받고 정비구역 파일 새 판을 확인하며, 다른 범위는 받지 않습니다. KB 지수와 아파트 실거래 지난 해는 '조회하기', 자동 확인, 공고 확인, 시세 통계 '지금 받기' 때 받습니다.
  - 자동 확인을 놓쳤는지 볼 때는 탭 하나만 돈 조회를 치지 않습니다.

## 네이버 (크롬 확장)

네이버 부동산은 프로그램이 조작하는 브라우저(`navigator.webdriver`)를 감지해 404로 보냅니다. 그 창에서는 사람이 직접 눌러도 튕깁니다. 이 감지를 피하는 설정은 넣지 않습니다.
대신 평소 크롬에 확장을 달아, **직접 네이버를 볼 때** 화면이 이미 받은 매물 데이터를 대시보드로 보냅니다.

설치(한 번만):

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `D:\dev\home-near-work\extension` 폴더를 고릅니다.

주소창 옆 퍼즐 아이콘에서 핀으로 고정하면 받은 개수가 아이콘에 보입니다.

쓰는 법:

- **아이콘을 누르면** 사이트 목록과 켜기/끄기 스위치가 나옵니다. 켜거나 끈 뒤에는 그 사이트 탭을 새로고침합니다.
  - 네이버 부동산: 동그라미 '새 N'과 '봤음' 표시가 됩니다(기본으로 켜짐).
  - 다방: 열 때 받은 방 목록이 대시보드 매물로 들어가고, 새 방이 알림 설정에 맞으면 알림이 뜹니다(사이트 화면 위 표시는 아직 없음).
  - 나머지(피터팬·직방·KB·호갱노노·당근·집토스): 준비 중입니다. 켜 두면 화면 구조를 모아 표시 기능을 준비합니다.
  - 맨 위 **바로 가기**에서 대시보드와 같은 사이트 바로 가기를 씁니다(고른 지역 가운데로 열기). 맨 아래에 '지금 화면 구조 보내기'가 있습니다.
  - **켜 둔 N곳 한 번에 열기:** 켜 둔 사이트를 새 창 하나에 엽니다. 팝업을 열면 이 버튼에 초점이 있어 Enter만 눌러도 됩니다. 버튼 아래에 열 곳·안 열어도 되는 곳·꺼 둔 곳이 보입니다.
- **지역(팝업):** 지도에 점선 원으로 그릴 지역을 켜고 끄고, 반경(300m~3km)을 바꾸고, 지웁니다.
  - **네이버 지도에서 찍어 추가:** 네이버 지도 탭에서 누르면 지도 위에 판이 깔립니다. 원하는 곳을 누르면 그곳을 가운데로 새 지역이 생깁니다.
    - 이름은 1km 안의 가까운 역으로 제안하고, 고칠 수 있습니다. 반경을 고르면 원이 미리 보입니다. Esc로 취소합니다.
    - 위치는 화면의 동그라미 위치로 계산하므로, 동그라미가 3개 이상 보일 때 됩니다.
  - **역으로 추가:** 대시보드가 아는 역 목록에서 고릅니다.
  - 대시보드가 켜져 있으면 대시보드 '지역' 탭과 같은 목록으로 맞춰집니다. 양쪽에서 바꿨으면 나중에 바꾼 쪽을 따릅니다.
  - 대시보드가 꺼져 있어도 확장에서 쓰고, 켜지면 맞춥니다.
  - 집토스와 법원경매 자동 조회는 아는 역 근처를 봅니다. 아는 역은 설정의 `knownStations`, 지역으로 만든 역, 찍어 추가한 곳 2km 안의 역입니다.
- **네이버 지도는 열기만 하면 됩니다.** 동그라미마다 매물 수를 기억해 두었다가(누르지 않아도), 다음에 열었을 때 수가 늘어난 동그라미에만 빨간 '새 N'을 붙입니다. 그것만 누르면 됩니다.
  - 처음 열 때(처음 보는 확대나 검색 조건 포함)는 기억만 하고 아무 표시도 없습니다.
  - 전에 본 범위에서 매물이 없던 자리에 새 동그라미가 생겨도 '새 N'입니다.
  - '새 N'은 누를 때까지 남습니다. 누른 동그라미는 회색이 되고 '봤음'이 붙습니다.
  - 수만 비교하므로, 하나가 빠지고 하나가 새로 올라와 수가 같으면 알 수 없습니다.
  - 검색 조건(거래 유형, 매물 종류 등)을 바꾸면 그 조건으로는 처음 보는 것으로 칩니다.
  - 기록은 확장 안에 저장돼서, 대시보드를 켜 두지 않아도 표시됩니다.
- **범위 표시:** 켠 지역(예: 강남역 1km)이 네이버 지도 위에 파란 점선 원으로 보입니다. 지도를 끄는 동안에는 잠깐 멈췄다가, 놓으면 다시 맞춰집니다.
- 화면이 받은 매물 데이터는 대시보드로도 모입니다. 대시보드의 네이버 매물에는 '봤음 · 어제'처럼 네이버 목록에서 마지막으로 본 때가 붙습니다.
  - 대시보드의 네이버 매물은 동그라미를 눌러 목록을 볼 때만 들어옵니다. 그래서 전부 한 번은 본 매물입니다.
  - 확장 0.4 이전에 누른 동그라미는 대시보드에는 '봤음'으로 있지만 지도에서는 다시 눌러야 회색이 됩니다.
- 대시보드가 꺼져 있어도 됩니다.
  - 그동안 본 매물 목록은 확장에 모아 두었다가(최대 300개) 대시보드가 켜지면 1분 안에 보냅니다. '봤음' 시각은 보낸 때가 아니라 본 때로 남습니다.
  - 지도 묶음 같은 나머지 데이터는 꺼져 있는 동안 버려질 수 있습니다.
  - 아이콘 숫자는 대시보드가 받은 개수이고, 빨간 `!`는 대시보드가 꺼져 있다는 뜻입니다. 봤음 표시는 그대로 됩니다.
- 확장은 스스로 넘기거나 누르지 않고, 요청을 새로 보내지도 않습니다.
- 공고 사이트(LH, SH, 서울주거포털, 마이홈, 고방, HUG, 청약홈)에서 직접 받은 첨부 파일만 그 위치와 받은 주소를 대시보드에 알립니다('downloads' 권한). 다른 곳에서 받은 파일은 알리지 않고, 파일을 읽는 것은 대시보드입니다. 대시보드가 꺼져 있으면 모아 두었다가 켜지면 알립니다.
- 로그인·개인 정보 요청은 읽지 않고, 전화번호·이메일로 보이는 값은 가립니다.
- 확장 파일이 바뀌면 1분 안에 스스로 다시 불러옵니다. 열려 있던 네이버 탭은 새로고침해야 다시 붙습니다.
